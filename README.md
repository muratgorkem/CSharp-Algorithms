## Tersine Kargo (oyun)

`KargoOyunu.cs` is a console prototype of a cargo/logistics sorting game. `Program.Main` starts it; run with `dotnet run`.
Sort cargo onto trucks with `1`/`2`/`3` before the belt timer runs out. Fragile items need the key + `ENTER`, explosives go to disposal with `SPACE`, live animals go to truck `4`. Earn gold to buy robots, a belt brake, insurance and themes. Energy (5) and rewarded ads are simulated.
